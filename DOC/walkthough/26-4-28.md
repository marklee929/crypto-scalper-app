## 실행 모드 UX 정리

### 목적
- `live = 정상 실행`, `demo = 테스트 실행`, `continuous = demo 지속 실행 옵션`으로 실행 의미를 정리했다.

### 변경
- `--mode` 기본값을 `live`로 변경
- `--once` 제거
- `--continuous` 추가
- `--mode demo`는 기본적으로 `--ticks`만큼 실행 후 종료
- `--mode demo --continuous`일 때만 무한 실행
- live 실행 전 symbol guard 추가
  - 빈 symbol 차단
  - fallback/default `BTC` 차단
- demo/live 실행 전 `[RUNTIME_CONFIG]` 출력 추가

### 실행 예시
- 기본/live 실행: `python run.py`
- 명시적 live 실행: `python run.py --mode live`
- demo 1회 테스트: `python run.py --mode demo --ticks 120`
- demo 지속 실행: `python run.py --mode demo --ticks 120 --continuous`

### 검증
- `python -m compileall core exchanges run.py tests`
- `python -m unittest discover -v`
- `python run.py --config config.yaml --mode demo --ticks 120`

맞아. 그 흐름이 더 정상적이야.

지금 코드는 `--mode` 기본값이 `demo`라서, 아무 옵션 없이 실행해도 demo로 들어가. 그리고 demo가 기본 continuous라서 더 헷갈리게 되어 있음. 현재 `parse_args()`에 `--mode` 기본값이 `demo`로 되어 있고, `--once`를 붙여야 한 번 돌고 끝나게 되어 있어. 

우리가 원하는 구조는 이거지.

```text
아무 mode 없음 → 정상 실행/live 성격
--mode live   → 정상 실행/live
--mode demo   → 테스트 1회 실행 후 종료
```

그래서 패치는 이렇게 가면 됨.


## 6. 주의사항

`--mode` 기본값을 `live`로 바꾸면 실수로 live가 실행될 수 있다.

따라서 기존에 추가 예정이던 live config guard가 반드시 같이 있어야 한다.

live 실행 전 아래 검증을 유지 또는 추가한다.

```python
def _validate_live_config(config: dict) -> None:
    symbol = str(config.get("symbol", "")).strip().upper()
    if not symbol:
        raise ValueError("live mode requires explicit symbol in config.")

    if symbol == "BTC":
        raise ValueError(
            "live mode is using fallback/default symbol BTC. "
            "Use an explicit config file such as --config config.robo.yaml."
        )
```

그리고 live/demo 실행 전 runtime config 로그를 출력한다.

```python
def _log_runtime_config(config: dict, mode: str) -> None:
    print(
        "[RUNTIME_CONFIG] "
        f"mode={mode} "
        f"symbol={config.get('symbol')} "
        f"quote={config.get('quote_currency')} "
        f"trade_size={config.get('trade_size_cash')} "
        f"min_trade={config.get('min_trade_cash')} "
        f"candle={config.get('candle_interval_sec')}s "
        f"state_path={config.get('state_path')} "
        f"strategy_log={config.get('strategy_log_path')}"
    )
```

## 7. 테스트 수정/추가

`tests/test_run_guards.py` 또는 관련 테스트에 추가한다.

```text
1. parse_args 기본 mode는 live
```
